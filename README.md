# Pozuelo Shuttle Club

Badminton Pozuelo Shuttle es la comunidad de bádminton de Pozuelo de Alarcón (Madrid) para jugar, mejorar y disfrutar del deporte en un ambiente cercano.

## ¿Qué ofrecemos?

- Entrenamientos semanales para todos los niveles.
- Grupos desde iniciación hasta nivel avanzado y competición.
- Sesiones en dos sedes de Pozuelo de Alarcón.

## Niveles

Tanto si nunca has jugado como si tienes experiencia, hay una opción para ti:

- Nunca he jugado
- Iniciación
- Intermedio
- Avanzado / competición
